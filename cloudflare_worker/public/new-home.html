FAQ
ForkMesh is an open-source, local-first workspace for Git, team chat, and coding agents. It combines collaboration in World, parallel agent work, Git review, delivery tools, and independent repository mirrors in one project loop.
ForkMesh launches Codex or Claude Code in an isolated Git worktree. You can follow and steer the session, inspect the branch and diff, and choose when to create a pull request — without leaving the desktop app.
ForkMesh works with Git and can complement an existing host. The goal is to move the working center of gravity back to machines you control and keep projects usable beyond one provider.
Repository mirrors live on independently operated desktop or headless nodes. Coordination services handle discovery and routing without becoming the canonical Git storage layer.
Run curl -fsSL https://forkmesh.com/install.sh | bash on macOS, Windows (via a Unix shell), or Linux. The script installs a SHA-256-verified binary for your platform. Or grab builds from the desktop page.
