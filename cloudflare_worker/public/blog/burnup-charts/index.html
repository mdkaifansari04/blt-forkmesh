Why it matters

Planning belongs beside code. This feature keeps triage, prioritization, and progress visible inside the same mesh that hosts the repository.

Built-in burnup charts show scope and completion over time, so you can see a release converging (or not) at a glance.

How ForkMesh handles it

ForkMesh treats issue state as repository-backed collaboration data, then layers fast desktop workflows, boards, milestones, charts, and quick capture on top.

In practice, Burnup charts is designed as part of the same local-first workflow as the rest of ForkMesh: the desktop node owns the data, the relay coordinates reachability, and the repository remains the durable unit of collaboration.

Where it fits

Use it when project management needs to remain usable offline, portable across mirrors, and close to the work itself.
