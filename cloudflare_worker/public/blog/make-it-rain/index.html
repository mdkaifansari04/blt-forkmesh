Make it rain

Donate to a single node, or spray a contribution across every node in the federation at once.

Feature 64 of 72FeatureAccounts, money & rewards3 min read

Why it matters

Make it rain gives ForkMesh a concrete mechanism for one donation split across the federation or sent to a chosen node. Donate to a single node, or spray a contribution across every node in the federation at once.

Preservation costs time, disk, bandwidth, and maintenance, so incentives need to point at the nodes and people doing the work. In ForkMesh, make it rain addresses that need at the feature level, keeping the behavior close to the repository instead of buried in a detached hosted layer.

How ForkMesh handles it

ForkMesh handles make it rain through the same split it uses across the product: ForkMesh links node identity, repository activity, public profiles, and Solana payment flows without changing Git ownership.

The behavior is intentionally narrow: Donate to a single node, or spray a contribution across every node in the federation at once. Support can move to maintainers, mirror operators, and contributors while repositories remain local-first.

Title focus: Make it rain stays tied to one donation split across the federation or sent to a chosen node and the local-first repository model.

Where it fits

Use make it rain when identity, support, and incentives should follow verifiable node and repository activity.

It pairs with the rest of Accounts, money & rewards because Make it rain keeps one donation split across the federation or sent to a chosen node connected to the repository, its signatures, and the nodes that serve it.
