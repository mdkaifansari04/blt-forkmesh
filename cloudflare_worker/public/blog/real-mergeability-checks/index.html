Real mergeability checks

Every PR is checked with a true three-way merge against the live base branch, so "can merge" means it will actually merge.

Feature 25 of 72FeaturePull requests & review3 min read

Why it matters

Code review is where trust and velocity meet. This feature makes review portable while preserving the familiar mechanics developers expect from modern forges.

Every PR is checked with a true three-way merge against the live base branch, so "can merge" means it will actually merge.

How ForkMesh handles it

ForkMesh combines Git branches, patch records, mergeability checks, review threads, and optional AI help inside the desktop repository workspace.

In practice, Real mergeability checks is designed as part of the same local-first workflow as the rest of ForkMesh: the desktop node owns the data, the relay coordinates reachability, and the repository remains the durable unit of collaboration.

This post is generated from the live ForkMesh feature catalog so the blog stays aligned with /features as the product surface grows.

Where it fits

Use it when contributors need to propose, discuss, merge, and recover changes without depending on one hosted pull-request database.

Together with the other features in Pull requests & review, it pushes ForkMesh toward a code forge that can be hosted, mirrored, reviewed, and funded by the people using it.
