What is ForkMesh?

ForkMesh is an open-source, local-first workspace for Git, team chat, and coding agents. It combines collaboration in World, parallel agent work, Git review, delivery tools, and independent repository mirrors in one project loop.

How do coding agents work?

ForkMesh launches Codex or Claude Code in an isolated Git worktree. You can follow and steer the session, review its branch and range diff, then choose when to create a pull request.

Does it replace GitHub or GitLab?

It can complement an existing source host. ForkMesh works with Git while moving the working center of gravity back to your machine and keeping useful copies beyond one provider.

Where does repository data live?

Git mirrors live on desktop or headless nodes. Coordination services handle discovery, rooms, account lookup, and healthy routing without becoming the canonical Git object store.

What happens if the source host goes offline?

If an eligible, healthy, integrity-matching mirror exists, ForkMesh can keep the same public project route browsable and cloneable from that independent copy.

Which platforms are supported?

The native app supports macOS, Windows, and Linux. ForkMesh also exposes workflows through the web, mobile app, VS Code extension, and MCP.
