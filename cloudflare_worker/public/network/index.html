Network architecture

Adapted from the redesign, corrected to match the current Worker + Durable Object implementation.

Catalog Durable Object

Maintains the public repository index and metadata returned by /api/repositories.

Host tunnel

Desktop nodes keep outbound WebSocket tunnels open, so private host IPs are not exposed to visitors.

Git clone protocol

git clone https://forkmesh.com/owner/repo streams upload-pack data from the active host.

Issue / PR sync

Signed issue and patch submissions can arrive through Worker inboxes, then become Git files when merged.

Encrypted rooms

Chat payloads are encrypted before relay; the room Durable Object broadcasts ciphertext and live counts.

Storage boundary

The Worker coordinates and relays. Canonical Git objects live on the hosting desktop mirror.

What users see

Users browse repositories through ForkMesh URLs. They see Cloudflare as the reachable edge, not the host node's real private address.
