# ForkMesh Qt client

Build and launch from this directory:

```sh
./run.sh
```

Run the main client test suites:

```sh
./run.sh test
```

For dependencies, first-run setup, UI workflows, pull requests, headless mode,
data locations, logs, and troubleshooting, use the canonical
[Qt client guide](../docs/qt-client.md).

New to ForkMesh? Start with [Getting started](../docs/getting-started.md).
Changing the project? Read [Contributing](../CONTRIBUTING.md) before opening a
pull request.
