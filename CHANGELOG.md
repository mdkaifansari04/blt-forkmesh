# ForkMesh Changelog

> Code hosting that lives on the network. Here's how ForkMesh grew, release by
> release — from a single mirror on one laptop to an agent-powered, self-funding
> developer mesh.

---

## v0.5.0 — "The Agent Mesh"
*June 2026*

The release where ForkMesh starts to feel alive. Open an issue, hand it to an
AI agent, and watch a real pull request show up — all without leaving the mesh.

- **Built-in coding agents.** Assign any issue to Claude Code or Codex straight
  from the issue detail or the quick-add box. The agent works on your connected
  fork and opens a pull request when it's done.
- **A real terminal, in the app.** A native VT100 terminal renders every agent
  and workflow run with full color output and emoji — no more flat, lifeless
  logs.
- **Bounties that pay out.** Fund any issue with a one-click Solana bounty.
  ForkMesh watches the chain, confirms the deposit, and releases the reward to
  the contributor when their PR is merged.
- **IDE extension.** Kick off ForkMesh agents from your editor.
- **Profile pages.** Click any node and see its full public profile — repos,
  identity, and the version it's running.
- **Hardened by default.** Tighter signup and relay security, with auto-publish
  off until you say so.

---

## v0.4.0 — "Autonomous Agents"
*June 2026*

Collaboration stopped being a one-person job.

- **Parallel agents, no queue.** Run multiple agents at once across your issues.
- **Continue the conversation.** Pick a session back up where it left off, and
  auto-check "create a PR" on quick tasks so work flows straight into review.
- **Live activity indicators.** See at a glance which agents are working right
  now.
- **Issues and PRs that talk to each other.** Merge a PR and its linked issue
  closes itself; merge with one checkbox to sync straight to main.
- **One-click delegation.** Send any issue to your agent of choice — pre-filled
  and ready to go.

---

## v0.3.0 — "Identity & Rewards"
*June 2026*

ForkMesh learned to pay the people who keep the network alive.

- **Anonymous accounts.** Sign up with nothing but a key and a password — no
  email, no phone. Optional 2FA included.
- **Solana payouts and donations.** Publish a Solana address and let anyone
  "make it rain" across a single node or the whole federation. SOL and USDT
  supported, priced live.
- **Rewards for mirroring.** The nodes that preserve code get recognized for it.
- **Network presence, done right.** Mirror-sync notices moved out of chat and
  into a proper network log, with live connection alerts.

---

## v0.2.0 — "Collaborate Anywhere"
*June 2026*

The web caught up to the desktop, and ForkMesh went mobile.

- **Pull requests.** Signed patch submissions, browsable on the web and
  mergeable from the client.
- **Actions.** Run real workflows on push, with the latest live log always one
  click away.
- **Releases and tags.** See your tags, mark the current one, and cut new
  releases in seconds.
- **Browse before you mirror.** Explore any repository — files, commits, and
  rich diffs (images shown side by side) — straight from the web, no clone
  required.
- **Mirror on your phone.** Carry the mesh in your pocket.
- **Fork with intent.** Choose exactly where a fork lands in your working tree.
- **QR everywhere** for fast, scannable handoffs.

---

## v0.1.0 — "Genesis"
*June 2026*

The first commit. A bet that source code shouldn't be locked to a single forge.

- **A distributed mirror network.** Local Git mirrors, signed identities, and a
  Cloudflare relay that coordinates without ever holding your objects.
- **A public catalog.** Every repository a node publishes, browsable on the web
  and streamed live from its host.
- **Issues that grow with you.** Open/closed states, priorities, custom fields,
  a Kanban board, and milestones with progress bars.
- **Commit history and diffs**, viewable right in the browser.
- **Encrypted room chat**, end-to-end encrypted before it ever touches the
  relay.
- **One-click hand-off to your AI tools**, baked in from day one.
